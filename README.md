# Исследование данных и поиск аномалий

Проект демонстрирует проверку качества данных, расчёт средней и медианной цены, поиск ценовых выбросов и визуализацию дневной выручки.

В `sales.db` находится воспроизводимый **синтетический учебный набор**, а не реальные продажи. Одна экстремальная цена намеренно добавлена для сравнения статистики с выбросом и без него.

## Запуск

```powershell
python -m pip install -r requirements.txt
python analysis.py
```

Скрипт проверит `sales.db` и создаст или обновит `sales_revenue.png` и `day3_report.md`. Если базы ещё нет, скрипт создаст её. Существующая база автоматически не перезаписывается.

Чтобы указать свою SQLite-базу и пути к результатам:

```powershell
python analysis.py --db sales.db --chart sales_revenue.png --report day3_report.md
```
